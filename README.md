# 🏠 3D Interior Design Studio

An interactive web application that allows users to design and visualize interior spaces in real-time using 3D rendering. The platform enables users to customize room layouts and place furniture dynamically within a 3D environment.

---

## 🚀 Features

* 🧱 Custom room generation with adjustable dimensions
* 🎨 Wall and floor customization
* 🛋️ Manual furniture placement inside rooms
* 🔄 Real-time 3D rendering using Three.js
* 📐 Dynamic room resizing based on user input
* 🧩 Modular and interactive UI design

---

## 🛠️ Tech Stack

### Frontend

* React.js
* TypeScript
* Three.js
* Tailwind CSS

### Backend

* Node.js
* Express.js

## ▶️ Run Locally

### 1. Clone the repository

```
git clone https://github.com/Pervaz-Hussain/3D-Interior-Design-Studio.git
cd 3D-Interior-Design-Studio
```

### 2. Install dependencies

```
npm install
```

### 3. Start the development server

```
npm run dev
```

---

## 📦 3D Assets Notice

Due to size limitations, 3D model files (.glb) are not included in this repository.

👉 To run the project properly:

* Add your `.glb` models inside:

```
public/models/
```

---

## 🧠 How It Works

1. User sets room dimensions through the UI
2. The system generates a 3D room structure
3. User customizes walls and floor
4. Furniture can be added manually from available assets
5. Scene updates in real-time using Three.js
